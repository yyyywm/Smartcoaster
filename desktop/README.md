# 智能杯垫桌面端 MVP

桌面端读取 ESP32-C3 的 JSON Lines 状态和饮水事件，在工作时段提醒喝水，并把饮水记录保存到本机 SQLite。依赖 Python 3.10+、Tkinter、`pyserial`、Pillow 和 `pystray`。

Windows 下应用会在创建窗口前启用 DPI 感知，让高分辨率屏幕上的文字按原生像素绘制。主界面采用无滚动条的单屏布局，初始窗口约为 1080 × 667（宽高比约 1.618），最小窗口约为 960 × 593；屏幕较小时会按可用空间缩小。

界面按钮采用连续曲率圆角，并提供悬停渐变、按压、键盘焦点和禁用反馈；设置输入框和卡片也使用圆角。按钮可用鼠标点击，也可聚焦后按 Enter 或空格触发。

## 主要功能

- 自定义上下班时间（支持跨午夜）、喝水间隔、每次提醒需喝的水量、每日目标和杯子容量。设置集中在「设置」页。
- 启动后自动按当前设置计时，无须点击开始。进入「设置」页期间暂不弹出新提醒，但计时继续；若在设置期间到点，返回其他页面后会提醒。达到时间阈值且设备在线时会在每块显示器上显示提醒；可喝足设定容量自动完成，也可在任意屏幕点「稍后提醒」。稍后提醒不计饮水，会在较短时间后再次提醒。收到设备补水事件时，默认用户已经喝过水，自动结束本次提醒、取消稍后提醒，并从补水时重新按正常间隔计时；补水不增加饮水统计。
- 「设置 → 提醒背景」可选择 PNG、JPG、WebP 或 BMP 图片，选好后点「保存设置」。图片会复制到数据库旁的 `reminder_images` 目录，原图移走后仍可使用。提醒文字显示在透出图片的浅色柔化面板上。默认“智能适配”：足够大的图按比例铺满并居中裁切；小图按原始尺寸或缩小后居中，四周用暗化的模糊背景补齐，不强行放大主体。也可手动选择“铺满（会裁切）”或“完整显示”；铺满模式可能放大小图，使其模糊。图片最大 30 MB、5000 万像素；文件丢失或损坏时使用默认纯色背景。
- Windows 标题栏和任务栏使用专属杯子图标；源文件在 `assets/`。
- Windows 下最小化主窗口会收进系统托盘，提醒计时和设备连接继续运行；点击托盘图标或选择「打开主界面」可恢复，托盘菜单的「退出」会关闭程序。主窗口的关闭按钮仍会直接退出。
- 「总览」只显示杯中水量、今日已确认饮水与提醒状态。把**空杯**放稳后连续点击两次记录空杯重；装满水放稳后可再连续点击两次记录满杯重。换杯后须重新标定。标定值会同步到新版固件并写入 NVS。
- 空杯和满杯都标定后，总览会根据稳定重量显示当前毫升数与动态水位百分比；水位变化平滑过渡。只有空杯标定时显示估算毫升数，不显示缺乏满杯基准的水位比例。拿走杯子、设备离线或称重未稳定时会清除水位，避免误读旧值。
- 尚未记录空杯重时，杯子放稳后仍会显示「已放杯」和杯+水总重（g）；此时不会把总重误标为水量（ml）。
- 若杯垫上没有任何物品却显示有杯，在「设置 → 杯子标定」中连续两次点击「杯垫空载归零」。归零会清除旧的空杯／满杯标定，之后须重新记录杯子重量。
- 按本机日期统计今日已记录饮水量、目标进度。「数据」页可分页查看记录、导出 CSV、删除选中、清空今日或全部；删除需在 30 秒内再次点击确认。旧版 `estimated` 数据单列，不计入已确认量。
- 顶部依次为「总览 → 统计 → 设置 → 数据」。「统计」页按周一到周日显示整个月，可切换月份或回到本月。每天显示称重确认的累计饮水量：达到当前每日目标为绿色，未达到为红色；无确认记录和未来日期为灰色。今天用蓝框标出，饮水记录新增、删除和日期变化会自动更新；修改每日目标后，历史日期也按当前目标重新判断。估算记录不计入达标量。
- 设备选择、刷新和连接/断开按钮位于顶部右侧、COM 状态左边，不再单独占用一行。串口列表按 COM 号排序并标识 ESP32-C3；可选自动查找或指定端口，单个按钮负责连接/断开，意外断线后自动重试。提供无硬件演示模式。

## 运行

### Windows 免安装分发包

双击分发包中的 `SmartCoaster.exe` 即可运行，无需安装 Python。使用说明见 [DISTRIBUTION.md](DISTRIBUTION.md)。个人数据仍保存在 `%LOCALAPPDATA%\SmartCoaster`，不随分发包提供。

开发者执行 `powershell -File desktop/build.ps1`，通过 `conda run -n dsh_coaster` 使用已有环境，在 `desktop/build/` 生成中间文件，在 `desktop/release/` 生成独立版本目录和 ZIP。包内附 MIT、第三方声明和许可。不覆盖旧版，不创建新环境；可用 `-CondaEnvironment 环境名` 指定已有环境，依赖已满足时加 `-SkipInstall`。详见 [维护与发布](../docs/MAINTENANCE.md)。

### 从源码运行

从项目根目录执行：

```powershell
conda activate dsh_coaster
python -s -X utf8 -m pip install -r desktop/requirements.txt
python desktop/smart_coaster.py                 # 自动查找设备
python desktop/smart_coaster.py --port COMx     # 指定当前串口，如 COM18
python desktop/smart_coaster.py --simulate --db demo.db  # 独立数据库演示
python desktop/smart_coaster.py --list          # 列出串口
python desktop/smart_coaster.py --selftest      # 离线测试
```

启动后自动尝试连接设备并运行提醒计时。可在顶部设备下拉框选择串口，点击「连接设备」；进入「设置」页可随时调整计划和标定，期间不会弹出新提醒。设备的 COM 号变化时点击「刷新」重新选择；使用「自动查找 ESP32-C3」时，应用会在设备重新出现后自动连接。点击「断开连接」会停止重试，直到再次连接。`--port` 只决定启动时的初始选择。

默认数据库位置为 `%LOCALAPPDATA%\SmartCoaster\coaster.db`（非 Windows 系统使用 `~/.local/share/SmartCoaster/coaster.db`）。可用 `--db 路径` 指定独立数据库。

## 提醒行为与边界

工作时段内，从上班时间、上次达标饮水时间或本次启动时间（取最晚者）开始计算正常喝水间隔。打开或离开设置页不会重置计时；修改设置后按新间隔计算，若已到点则返回其他页面后提醒。关闭提醒后改为短暂稍后提醒：**取 5 分钟与正常间隔一半中的较短者**，因此始终早于下一次正常间隔。稍后期间若确认喝足，则取消稍后提醒并从饮水时间重新计算正常间隔。若到点时设备不在线，等设备恢复状态上报后再提醒。提醒出现后若设备断线，全屏暂时收起，主界面显示待完成提醒；设备恢复后会再次显示。关闭软件后重新启动会清除上一会话未完成的全屏提醒，保留饮水统计，并自动重新计时。

桌面端独立计算提醒时间，不使用固件的 `remind` 事件；固件仍可向串口输出该事件。

多显示器时每块屏幕都有提醒窗口，在任意屏幕点「稍后提醒」会一起关闭。也可按 `Esc`、`Alt + F4` 或 `Ctrl + Shift + Q` 关闭；主界面继续运行。关闭提醒不会新增饮水记录，也不会把它算作喝水达标。关闭主窗口才会退出应用，应用必须保持运行才能继续提醒。

称重差值只能证明杯中重量减少，不能证明水确实被喝下。今天的数字是杯垫记录的非估算重量差；倒水、换杯或传感器误差可能影响它。空杯标定用于计算杯中水量，满杯标定还提供容量上界；约按 1 g ≈ 1 ml 换算。拿杯期间喝水后直接加水，杯垫无法反推饮水量；检测到净增加并上报补水时，只跳过本次提醒，不统计未知水量。纯加水也按同一规则处理。放回重量与拿起前相同，或净增加未超过固件补水阈值（默认 15 g）时没有补水事件，无法自动跳过提醒。

## 目录

| 路径 | 职责 |
|---|---|
| `smart_coaster.py` | 命令行入口 |
| `coaster_app/model.py` | 时间窗口、饮水达标与提醒规则 |
| `coaster_app/storage.py` | SQLite 设置、提醒状态和饮水记录 |
| `coaster_app/transport.py` | 串口自动重连与演示数据 |
| `coaster_app/ui.py` | Tk 仪表盘与全屏提醒 |
| `coaster_app/tray.py` | Windows 托盘图标和打开／退出操作 |
| `coaster_app/soft_button.py` | 连续曲率按钮与交互反馈 |
| `coaster_app/rounded_panel.py` | 圆角卡片和输入框表面 |
| `coaster_app/water_view.py` | 双点标定后的动态水位组件 |
| `coaster_app/calendar_view.py` | 周一开始的自适应月历与每日达标状态 |
| `coaster_app/reminder_image.py` | 自定义提醒背景的导入与适配 |
| `tests/` | 脱离硬件的规则与存储测试 |
