# 智能杯垫 · 饮水提醒

Windows 64 位免安装版，已包含 Python 运行环境及所需依赖。

## 开始使用

1. 解压整个 ZIP 文件到本地文件夹。
2. 双击 SmartCoaster.exe，无需安装 Python，无需管理员权限。
3. 用支持数据传输的 USB 线连接已烧录配套固件的 ESP32-C3 杯垫。
4. 默认自动查找设备；也可在顶部选择对应 COM 端口并连接。
5. 首次使用在“设置”中配置上下班时间、每日目标等，并完成空杯和满杯标定。

顶部导航依次为“总览 → 统计 → 设置 → 数据”。
统计月历以周一开始，达标绿色、未达标红色；无记录及未来日期灰色。
统计只计入称重确认的饮水量，历史记录也按当前每日目标判断。

## 提醒和退出

请保持程序运行，工作时段内设备在线时会按设置弹出全屏提醒。
最小化会收进系统托盘，提醒仍继续；点击托盘图标可恢复窗口。
关闭主窗口，或在托盘菜单中选择“退出”，会结束程序。
请避免同时打开多个程序实例，以免争用串口。

## 数据保存与升级

设置、标定值和饮水记录保存在当前 Windows 用户目录：
%LOCALAPPDATA%\SmartCoaster\coaster.db

自定义提醒背景保存在同目录下的 reminder_images 文件夹。
升级时先退出旧版，再解压并运行新版；上述数据目录会继续使用。
需要备份时，可先在“数据”页导出 CSV；要完整备份，请退出程序后复制整个 SmartCoaster 数据目录。
分发包不包含开发者个人记录、设置、照片或固件；每台电脑独立保存数据。

## 无硬件演示

命令行参数：SmartCoaster.exe --simulate --db demo.db
这会将演示数据写入独立的 demo.db，避免混入正式记录。
