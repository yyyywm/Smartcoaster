# CAD 操作约定

- 用户要求：以后操作 SolidWorks，除特殊情况外，默认使用 SolidWorks MCP，包括打开、查询、建模、修改引用、保存和导出。
- MCP 的 `sw_execute_script` 可用于工具未直接封装的 API；不默认从终端运行独立 pywin32/COM 脚本。仅在 MCP 不可用或确实无法完成任务时使用备选，并说明具体原因。
- `scripts/legacy/` 是旧版重生成备份，不是默认操作入口；不要为验证路径而执行它们或覆盖用户模型。
- 默认修改 `models/` 当前版本。`archive/` 是历史设计，仅在整理引用或用户明确要求时修改；其传感器副本用于冻结历史引用，不自动同步到当前版本。
- 移动装配或零件前，用 MCP 读取实际依赖；移动后用 MCP 更新引用并验证实际加载路径。不能仅凭文件名猜版本组合。
- 原生文件名保留；最新装配入口为 `models/Smart_Coaster_layout_v5.SLDASM`。导出物分别放在 `exports/stl/`、`exports/step/`。
- 验证时不要保存无关文档。完成的独立零件及时保存并关闭；装配引用的零件可随装配加载。避免关闭其他会话或用户的未保存文档。
- 坐标和单位以 API 文档为准；不在未确认参数顺序时猜测 COM 方法。文件整理不等于完成干涉、强度、制造或实物验证。
