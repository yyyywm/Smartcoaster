# 测试与验证记录

## 桌面端

从仓库根目录运行，需要可用的 Windows 图形桌面；部分测试会创建并关闭 Tk 窗口。

```powershell
conda run --no-capture-output -n dsh_coaster python -s -X utf8 desktop/smart_coaster.py --selftest
```

覆盖设置、工作时段、饮水/补水、提醒/稍后提醒、SQLite/CSV、串口选择、标定、图片、多显示器、DPI、图标、托盘和最小窗口布局。

月历覆盖本机日汇总、超过 200 条记录、排除估算、重启后查询、删除、目标变更、未来日期、跨午夜/年、闰年和回到本月。

反复创建 Tk 根窗口时，部分 Tk 版本可能输出 `ThemeChanged: application has been destroyed`。应核对断言、最终 `OK` 和退出码，不能单凭该文本判断测试成功或失败。

## 固件宿主测试

```powershell
make -C firmware/tests test
```

需 GCC 和 GNU Make，也可 `make -C firmware/tests test CC=gcc`。输出是状态机与协议的断言数，不是 Python 用例数。不覆盖 HX711 实际 GPIO 时序、NVS 断电或主任务集成，详见 `firmware/tests/README.md`。
