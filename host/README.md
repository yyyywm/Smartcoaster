# 智能杯垫桌面端 MVP

桌面端读取 ESP32-C3 的 JSON Lines 状态和饮水事件，在工作时段提醒喝水，并把饮水记录保存到本机 SQLite。只依赖 Python 3.10+、Tkinter 和 `pyserial`。

Windows 下应用会在创建窗口前启用 DPI 感知，让高分辨率屏幕上的文字按原生像素绘制。主界面采用无滚动条的单屏布局，初始窗口约为 1080 × 667（宽高比约 1.618），最小窗口约为 960 × 593；屏幕较小时会按可用空间缩小。

## 主要功能

- 自定义上下班时间（支持跨午夜）、喝水间隔、每次提醒需喝的水量、每日目标和杯子容量。设置集中在「设置」页。
- 启动后自动按当前设置计时，无须点击开始。进入「设置」页期间暂停新提醒，离开设置页后按新设置重新计时。达到时间阈值且设备在线时显示置顶全屏提醒。普通关闭操作不会解除提醒；收到足量的**非估算** `drink` 事件后自动解除。
- 「总览」只显示杯中水量、今日已确认饮水与提醒状态。把**空杯**放稳后连续点击两次记录空杯重；装满水放稳后可再连续点击两次记录满杯重。换杯后须重新标定。标定值会同步到新版固件并写入 NVS。
- 尚未记录空杯重时，杯子放稳后仍会显示「已放杯」和杯+水总重（g）；此时不会把总重误标为水量（ml）。
- 按本机日期统计今日已记录饮水量、目标进度。「数据」页可分页查看记录、导出 CSV、删除选中、清空今日或全部；删除需在 30 秒内再次点击确认。旧版 `estimated` 数据单列，不计入已确认量。
- 串口列表按 COM 号排序并标识 ESP32-C3；可选自动查找或指定端口，单个按钮负责连接/断开，意外断线后自动重试。提供无硬件演示模式。

## 运行

从项目根目录执行：

```powershell
python -m pip install -r host/requirements.txt
python host/smart_coaster.py                 # 自动查找设备
python host/smart_coaster.py --port COMx     # 指定当前串口，如 COM18
python host/smart_coaster.py --simulate      # 无硬件演示
python host/smart_coaster.py --list          # 列出串口
python host/smart_coaster.py --selftest      # 离线测试
```

启动后自动尝试连接设备并运行提醒计时。可在顶部设备下拉框选择串口，点击「连接设备」；进入「设置」页可随时调整计划和标定，期间不会弹出新提醒。设备的 COM 号变化时点击「刷新」重新选择；使用「自动查找 ESP32-C3」时，应用会在设备重新出现后自动连接。点击「断开连接」会停止重试，直到再次连接。`--port` 只决定启动时的初始选择。

默认数据库位置为 `%LOCALAPPDATA%\SmartCoaster\coaster.db`（非 Windows 系统使用 `~/.local/share/SmartCoaster/coaster.db`）。可用 `--db 路径` 指定独立数据库。

## 提醒行为与边界

工作时段内，从上班时间、上次达标饮水时间或本次启动／离开设置页的时间（取最晚者）开始计算间隔。若到点时设备不在线，等设备恢复状态上报后再提醒。提醒出现后若设备断线，全屏暂时收起，主界面显示待完成提醒；设备恢复后会再次显示。关闭软件后重新启动会清除上一会话未完成的全屏提醒，保留饮水统计，并自动重新计时。

桌面端独立计算提醒时间，不使用固件的 `remind` 事件；固件仍可向串口输出该事件。

全屏窗口使用 Tk 的置顶与焦点保持，普通关闭按钮和 `Esc` 不会解除提醒。**普通桌面应用无法可靠阻止操作系统级切屏或强制结束进程**；为避免设备故障时无法使用电脑，始终保留 `Ctrl + Shift + Q` 紧急关闭整个软件。应用必须保持运行才能提醒。

称重差值只能证明杯中重量减少，不能证明水确实被喝下。今天的数字是杯垫记录的非估算重量差；倒水、换杯或传感器误差可能影响它。空杯标定用于计算杯中水量，满杯标定还提供容量上界；约按 1 g ≈ 1 ml 换算。拿杯后喝了一口又补到原重量时，杯垫无法确认饮水量，因此不会记账。

## 目录

| 路径 | 职责 |
|---|---|
| `smart_coaster.py` | 命令行入口 |
| `coaster_app/model.py` | 时间窗口、饮水达标与提醒规则 |
| `coaster_app/storage.py` | SQLite 设置、提醒状态和饮水记录 |
| `coaster_app/transport.py` | 串口自动重连与演示数据 |
| `coaster_app/ui.py` | Tk 仪表盘与全屏提醒 |
| `tests/` | 脱离硬件的规则与存储测试 |
