# 智能杯垫桌面端 MVP

桌面端读取 ESP32-C3 的 JSON Lines 状态和饮水事件，在工作时段提醒喝水，并把饮水记录保存到本机 SQLite。只依赖 Python 3.10+、Tkinter 和 `pyserial`。

Windows 下应用会在创建窗口前启用 DPI 感知，让高分辨率屏幕上的文字按原生像素绘制。窗口较小时可使用右侧滚动条查看全部内容。

## 主要功能

- 自定义上下班时间（支持跨午夜）、喝水间隔、每次提醒需喝的水量、每日目标和杯子容量。
- 达到时间阈值且设备在线时显示置顶全屏提醒。普通关闭操作不会解除提醒；收到足量的**非估算** `drink` 事件后自动解除。提醒进度和计时状态会保存，重启应用后继续。
- 显示杯中估算水量和液位。首次使用时，把**空杯**放在杯垫上，待状态稳定，点击「记录空杯重」。此后水量约等于杯垫总重量减空杯重；换杯后须重新记录。
- 尚未记录空杯重时，杯子放稳后仍会显示「已放杯」和杯+水总重（g）；此时不会把总重误标为水量（ml）。
- 按本机日期统计今日已记录饮水量、目标进度与最近记录。固件标为 `estimated` 的续杯估算单独显示，不计入已确认量。
- 界面可刷新串口列表，选择自动查找 ESP32-C3 或指定 COM 口，并可连接、切换和断开；意外断线后会自动重试。提供无硬件演示模式。

## 运行

从项目根目录执行：

```powershell
python -m pip install -r host/requirements.txt
python host/smart_coaster.py                 # 自动查找设备
python host/smart_coaster.py --port COM18    # 指定串口
python host/smart_coaster.py --simulate      # 无硬件演示
python host/smart_coaster.py --list          # 列出串口
python host/smart_coaster.py --selftest      # 离线测试
```

启动后在顶部「连接设备」下拉框选择串口，点击「连接」。设备的 COM 号变化时点击「刷新」重新选择；使用「自动查找 ESP32-C3」时，应用会在设备重新出现后自动连接。点击「断开」会停止重试，直到再次点击「连接」。`--port` 只决定启动时的初始选择。

默认数据库位置为 `%LOCALAPPDATA%\SmartCoaster\coaster.db`（非 Windows 系统使用 `~/.local/share/SmartCoaster/coaster.db`）。可用 `--db 路径` 指定独立数据库。

## 提醒行为与边界

工作时段内，从上班时间或上次达标饮水时间开始计算间隔。若到点时设备不在线，等设备恢复状态上报后再提醒。提醒出现后，即使下班或暂时断线，也会保持，直到收到累计达到设定容量的确认饮水事件。

桌面端独立计算提醒时间，不使用固件的 `remind` 事件；固件仍可向串口输出该事件。

全屏窗口使用 Tk 的置顶与焦点保持，普通关闭按钮和 `Esc` 不会解除提醒。**普通桌面应用无法可靠阻止操作系统级切屏或强制结束进程**；为避免设备故障时无法使用电脑，始终保留 `Ctrl + Shift + Q` 紧急退出。应用必须保持运行才能提醒。

称重差值只能证明杯中重量减少，不能证明水确实被喝下。今天的数字是杯垫记录的非估算重量差；倒水、换杯或传感器误差可能影响它。水量显示依赖空杯重和固件的称重系数，约按 1 g ≈ 1 ml 换算。

## 目录

| 路径 | 职责 |
|---|---|
| `smart_coaster.py` | 命令行入口 |
| `coaster_app/model.py` | 时间窗口、饮水达标与提醒规则 |
| `coaster_app/storage.py` | SQLite 设置、提醒状态和饮水记录 |
| `coaster_app/transport.py` | 串口自动重连与演示数据 |
| `coaster_app/ui.py` | Tk 仪表盘与全屏提醒 |
| `tests/` | 脱离硬件的规则与存储测试 |
